# Cómo contribuir

¡Gracias por tu interés en NodeXchange!

1. **Acepta el CLA.** Antes de que podamos aceptar tu primer *pull request*, debes aceptar el [Acuerdo de Licencia para Contribuidores](CLA.md). Basta con dejar en el PR el comentario que indica la sección 6.
2. **Abre un *issue* primero** si el cambio es grande, para conversarlo antes de que inviertas tiempo.
3. **Pasa las pruebas:** `pnpm --filter @nodexchange/core test`.

Si haces un fork, revisa la [política de marca](TRADEMARK.md): puedes usar el código libremente según la AGPL-3.0, pero no el nombre ni el logo de NodeXchange.
