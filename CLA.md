# Acuerdo de Licencia para Contribuidores (CLA)

Gracias por querer contribuir a NodeXchange. Antes de aceptar tu contribución necesitamos que aceptes este acuerdo. Sirve para que el proyecto pueda seguir distribuyendo, mantener y licenciar el código a largo plazo, y para que quede claro que tu aporte es tuyo y puedes compartirlo.

En tu primer *pull request*, agrega este comentario:
